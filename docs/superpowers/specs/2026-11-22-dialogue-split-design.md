# 대사 나누기 (마스터 편집 화면) — 설계

## 왜

`2026-09_Lv6` 마스터 1~4장은 대사가 서술 사이에 묻힌 한 덩어리 문단이다(2장 1문단·따옴표 6개, 3장 1문단·따옴표 20개). 번역본(Layer 5)은 마스터의 문단 구성을 그대로 따르므로, 승인 전에 마스터에서 대사를 나눠 두면 모든 언어가 같은 구조로 만들어진다. 기존 "문단 구성 제안"(Claude)은 장면·화자가 바뀌는 곳만 문장 앞에서 제안하는 도구라 대사를 빠짐없이 분리하는 용도에는 맞지 않는다.

## 목표 / 비목표

- 목표: 검토 모드의 한 장에서 버튼 한 번으로 대사를 문단으로 나눈 결과를 미리 보고, 확인한 뒤 적용한다.
- 목표: 같은 입력이면 항상 같은 결과(규칙 기반, Claude 호출 없음). 글자는 하나도 바꾸지 않고 문단 경계만 바뀐다.
- 비목표: 게시본 편집(`published` 모드)에서의 사용 — 문단 수가 고정이라 기존 구조 제안 패널처럼 검토 모드 전용이다.
- 비목표: 따옴표 안의 화자 판별, 모든 장 일괄 적용, 따옴표 스타일 변환.
- 안티 목표: 대사 중간(`잡고 “…”라는 안내 방송을`)처럼 문장 안에 들어간 인용을 쪼개 문장을 깨뜨리는 것.

## 접근 (사용자가 1번 선택)

1. 규칙으로 나누기 — **선택**. 결정적이고 무료이며 글자를 바꾸지 않는다.
2. Claude에게 맡기기(기존 제안 패널 확장) — 문장 중간 판단은 되지만 비용·재현성 문제로 제외.

## 규칙 (사용자 결정: 서술은 대사 문단에 붙인다)

마스터 본문의 대사 따옴표는 두 종류가 섞여 있다. 전 세션을 훑어 보니 대부분 곧은 따옴표 `"`이고(2026-09_Lv6도 굽은 31개 + 곧은 28개), 일부만 굽은 `“ ”`이다. 그래서 둘 다 대사로 본다. 작은따옴표(`‘ ’`, `'`)는 책 제목·속마음·아포스트로피라 대사로 보지 않는다. 곧은 `"`는 여는지 닫는지 모양으로 알 수 없으므로 문단 안에서 나타나는 순서대로 열기→닫기를 번갈아 센다(굽은 `“`는 항상 열기, `”`는 항상 닫기). 아래 "여는 따옴표"는 이렇게 가려낸 여는 따옴표를 뜻한다.

- 문단 안에서 **여는 따옴표가 문장 시작 위치에 있으면 그 앞에서 문단을 나눈다.** 문장 시작 위치 = 문단 맨 앞이거나, 바로 앞(공백 제외)이 문장 끝 부호(`.` `!` `?` `…`) 또는 닫는 따옴표.
- 대사 **뒤에 이어지는 서술은 그 대사 문단에 남긴다**(다음 대사가 나오기 전까지). 대사 앞의 서술은 앞 문단에 남는다.
- 닫는 따옴표 바로 뒤에 다시 여는 따옴표가 오면(대사 연속) 거기서도 나눈다.
- 문장 중간에 든 인용(앞이 쉼표·조사·일반 글자, 또는 뒤가 `라고`·`라는`·`이라는`처럼 이어지는 경우)은 나누지 않는다.
- 문단 맨 앞의 여는 따옴표에서는 나눌 것이 없다. 이미 나뉜 문단 경계는 그대로 둔다(여러 번 적용해도 결과가 같다).
- 열기·닫기가 짝이 맞지 않는 문단(곧은 따옴표 개수가 홀수이거나 굽은 따옴표 짝이 어긋남)은 건드리지 않고, 미리 보기에서 건너뛴 문단 번호를 알려 준다.
- 나눈 조각은 앞뒤 공백을 다듬고, 비는 조각은 만들지 않는다. 조각을 공백 하나로 이으면 원문과 같다(공백 차이 제외).

## 화면

`StructureSuggestions` 패널과 같은 자리(검토 모드, 현재 장)에 "대사 나누기" 버튼을 둔다. 누르면 서버 호출 없이 즉시 계산해 `N문단 → M문단` 미리 보기와 `이 구성으로 적용` / `적용하지 않고 닫기`를 보여 준다. 적용은 기존 `onApply`와 같은 경로(`updateChapter`)라서 자동 저장·나란히 보기·`수정됨` 표시가 그대로 붙는다. 나눌 곳이 없으면 "나눌 대사를 찾지 못했어요"를 보여 준다. 미리 보기는 열려 있는 동안 현재 본문으로 매번 다시 계산하므로(즉시 계산되는 순수 함수라서) 낡은 제안이 생기지 않는다. 장을 바꾸면 패널은 닫힌 상태로 새로 시작한다.

## 빌더에게 남긴 것

- 순수 함수 `splitDialogue(paragraphs: string[])`의 위치·이름, 컴포넌트를 기존 패널 안에 둘지 옆에 둘지(옆에 두는 쪽을 권장 — Claude 제안 상태와 섞이지 않는다).
- 테스트: `2026-09_Lv6` 2·3·10장에서 본 모양(대사→새 문장 서술, 연속 대사, 문장 중간 인용 `“…”라는`, `“…”, “…”` 쉼표 연결, 따옴표 짝 불일치, 이미 나뉜 문단, 중복 적용 불변).

## 알려 둘 한계

- 대사 뒤에 긴 장면 서술이 이어지면 그 서술도 대사 문단에 붙는다. 그런 곳은 기존 "문단 구성 제안"으로 더 나눌 수 있다.
- 한 따옴표 안의 화자 교대(`“…” “…”` 사이에 서술이 끼지 않은 경우)는 따옴표 경계마다 나뉘므로 대사가 한 줄씩 문단이 된다.
