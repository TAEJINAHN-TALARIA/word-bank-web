# Word Bank 랜딩페이지 리디자인

## 배경

`word-bank-web`은 React Native 앱 `word-bank`(WordBank / "Word Bank")의 홍보용 랜딩페이지다 (Next.js, `app/page.tsx` 단일 페이지). 현재 페이지는 앱 초기 버전 기준으로 작성되어 있어 최근 추가된 기능(READ 탭, 복습 3모드, 카테고리 관리)이 반영되어 있지 않고, 지원 언어 수(14개)도 예전 값(10개)으로 표기되어 있다.

앱 소스(`C:\Users\TAEJIN\Documents\word-bank`)를 조사한 결과:
- 핵심 기능: 단어 추가(AI 자동 생성) / 단어장(언어·카테고리별 정리) / 플래시카드 복습(Leitner 5단계, Classic·Cloze·Listening 3모드) / 복습 알람 / 알림창 빠른 추가 / 엑셀 내보내기 / READ 탭(AI 생성 리딩 콘텐츠, 탭-투-딕셔너리)
- 지원 언어: `src/shared/constants/languages.ts` 기준 14개 (한국어, 영어, 일본어, 중국어, 독일어, 프랑스어, 스페인어, 포르투갈어, 아랍어, 라틴어, 힌디어, 벵골어, 러시아어, 인도네시아어)
- iOS는 번들 ID가 템플릿 기본값 그대로라 스토어 출시 전 상태 — "iOS 준비 중"으로 표기
- 스크린샷은 사용하지 않고 기존처럼 이모지/아이콘 기반 스타일 유지하기로 결정

## 목표

`app/page.tsx`를 앱의 실제 사용 흐름(읽기 → 저장 → 정리 → 복습)을 따라가는 스토리텔링형 구조로 리디자인하고, 최신 기능과 정확한 언어 수를 반영한다.

## 범위

- `app/page.tsx` 리디자인 (Hero, 핵심 흐름 4섹션, 기타 기능 그리드, 지원 언어 섹션, CTA, Footer)
- `app/layout.tsx`의 메타데이터(title/description/OG) 업데이트 — 최신 기능 반영
- **범위 제외**: `app/privacy/page.tsx`(개인정보처리방침)는 법률 문서이므로 이번 작업에서 건드리지 않음. 실제 스크린샷 사용 안 함(이모지/아이콘 유지).

## 디자인

### 1. Hero (기존 유지 + 보강)
기존 카피("호기심을 저축하세요" / "모르는 단어를 발견했나요? 저장하기만 하세요. AI가 즉시 뜻, 예문, 유의어까지 찾아드려요.")는 앱 온보딩 문구와 톤이 일치하므로 그대로 유지한다. Google Play 다운로드 버튼 아래에 "iOS 버전은 준비 중입니다"라는 보조 텍스트를 작게 추가한다.

### 2. 핵심 흐름 섹션 (읽기 → 저장 → 정리 → 복습)
앱의 실제 사용 흐름 순서로 4개의 큰 섹션을 배치한다. 각 섹션은 아이콘 + 제목 + 설명으로 구성되고, 기존 기능 카드보다 크게 보이도록 데스크톱(`sm` 이상)에서는 홀수/짝수 섹션마다 텍스트 정렬을 좌우로 교차시키고, 모바일에서는 세로로 중앙 정렬해 쌓이도록 한다. 스크롤하면서 스토리처럼 읽히게 하는 것이 목적.

| 순서 | 아이콘 | 제목 | 설명 |
|---|---|---|---|
| 1. 읽기 | 📖 | 읽으면서 단어를 만나요 | 10개 언어, 6단계 레벨의 AI 생성 이야기로 읽기 연습을 해보세요. 모르는 단어가 나오면 탭 한 번으로 바로 뜻을 확인할 수 있어요. |
| 2. 저장 | ✨ | 탭 한 번으로 저장, AI가 나머지를 채워요 | 읽다가 발견했든 직접 입력했든, 저장하기만 하세요. AI가 즉시 품사·뜻·발음기호·예문·유의어·반의어까지 찾아드려요. |
| 3. 정리 | 🗂️ | 나만의 방식으로 정리해요 | 언어별, 혹은 직접 만든 카테고리별로 단어장을 정리하세요. 색상을 지정하고 검색하고, 필요하면 엑셀로 내보낼 수 있어요. |
| 4. 복습 | 🃏 | 잊을 만할 때 복습해요 | Leitner 5단계 박스로 아는 단어는 간격을 두고, 모르는 단어는 자주 복습해요. 카드 뒤집기·빈칸 채우기·듣고 맞추기 세 모드 중 골라보세요. |

### 3. 기타 기능 그리드
기존 카드 그리드 스타일(아이콘 + 제목 + 설명, `sm:grid-cols-2 lg:grid-cols-3`)을 재사용해 부가 기능을 나열한다.

- 🔔 복습 알람 — 원하는 시간에, 원하는 범위(언어/카테고리/모드)로 복습 알림을 받아보세요.
- ⚡ 알림창 빠른 추가 — 다른 앱에서 단어를 발견했다면 알림창에서 바로 추가할 수 있어요.
- 📊 엑셀 내보내기 — 저장한 단어장을 .xlsx 파일로 내보내 원하는 방식으로 활용하세요.
- 🌙 다크 모드 — 라이트/다크/시스템 테마를 지원해요.

### 4. 지원 언어 섹션 (신규)
14개 지원 언어를 배지(pill) 형태로 나열하는 섹션을 새로 추가한다: 한국어, 영어, 일본어, 중국어, 독일어, 프랑스어, 스페인어, 포르투갈어, 아랍어, 라틴어, 힌디어, 벵골어, 러시아어, 인도네시아어.

### 5. 다운로드 CTA + Footer
페이지 하단에 Google Play 다운로드 버튼을 한 번 더 배치한다. Footer의 저작권 연도를 2025 → 2026으로 갱신한다 (그 외 footer 구조/문구 유지).

### 6. 메타데이터 업데이트 (`app/layout.tsx`)
`title`/`description`/`openGraph`에 READ 탭 등 최신 기능이 드러나도록 문구를 다듬는다 (예: AI 자동 생성, 읽기, 복습을 함께 언급).

## 에러 처리 / 예외
정적 콘텐츠 페이지이므로 별도 에러 처리 로직 없음. 다크모드는 기존과 동일하게 Tailwind `dark:` 클래스로 처리한다.

## 테스트
- `npm run build`(또는 `next build`)로 정적 빌드 성공 확인
- 로컬에서 `npm run dev`로 라이트/다크 모드, 데스크톱/모바일 뷰포트에서 레이아웃 확인
- 기존 `/privacy` 링크 및 Google Play 링크 정상 동작 확인
